# PyHelper v1.0.0 Release Notes

## 包含能力

- 欢迎语、鼓励语和心情建议
- 学习记录新增、列表、搜索、统计
- JSON 持久化、导入导出、旧文本迁移
- dataclass 模型：`Note` / `StudyPlan`
- argparse CLI：`add/list/search/export/stats/advice/plan/review`
- agent team：Reader / Planner / Reviewer
